# Al-Naas Restaurant ERP — QA Documentation

## Project Overview
Al-Naas Restaurant ERP is a restaurant management system developed to support restaurant operations. This repository contains QA documentation prepared during testing of the live project.

## My Contribution
I collaborated with the project team as a QA tester, focusing on identifying application issues and documenting defects. I prepared bug reports and communicated identified issues to the development team for review.

- Administration — Users
- Administration — Roles
- HR — Designation
- HR — Employee Management
- Authentication and Session Management
