# Al Naaz Restaurant ERP — QA Documentation
QA testing documentation for Al Naaz Restaurant ERP, including manual testing activities, bug identification, and defect reporting for a live project.

## Project Overview
Al Naaz Restaurant ERP is a restaurant management system developed to support restaurant operations. This repository contains QA documentation prepared during testing of the live project.

## My Contribution
